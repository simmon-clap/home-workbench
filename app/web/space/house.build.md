# 全屋空间视图（生成物）

- **来源**：`app/prototype/spatial/build_house.mjs` 读取 `data/house.json` 离线生成
- **重新生成**：`node app/prototype/spatial/build_house.mjs`
- **为什么是生成物**：10 个房间的几何与家具是**离线**规则化摆好的（不该在浏览器里每次重算）；
  几何/家具另存于 `data/house.json`（由米家分区图 floorplan.json + 主屏 LAYOUT 规则化而来）（可读、可替换、可编辑后重生成），页面不是唯一真相源。
- **不是冻结的图**：页面运行时只读 `/api/state` —— 房间异常色、设备点（在线/离线/安全域形状）都按真实状态画。
- **零第三方**：不引用任何外部 JS/CSS，无 `node_modules`；运行期只用内联脚本。
- **体积**：约 108 KB（规范上限 1.5MB）。
- **与扫描快照的分工**：`/space/` 是米家分区图的扫描几何快照（核对用，5 个分区）；
  本页是产品里的全屋视图（10 个房间 + 家具 + 实时设备点）。
- **怎么改**：改 `data/house.json`（房间矩形 / 家具零件 / 门洞 / 窗）→ 重跑上面的命令即可，不改产品代码。
- **规范**：02 §13 空间视图（静态 SVG + CSS 过渡、四维度高亮）、11 v1.2 §13 已声明生成物。

- **待规范同步**：02 §13 写的是「几何来自 data/floorplan.json」；本页用 `data/house.json`（扫描几何只有 5 个分区、主屏有 10 个房间）。规范措辞需要一次小同步，待你批准；不影响运行。
